# Supabase

- El esquema, las migraciones y las Edge Functions (`create-user`) pertenecen al
  repositorio web CMAA y se despliegan desde allí.
- La app consume el proyecto de staging `dmdysvqailticvodbmyl`
  (configurado en `supabase.properties`).
- Nunca apliques cambios de esquema desde este repositorio.
